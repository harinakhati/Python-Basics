# Python Basics Learning Repository

A comprehensive, structured learning resource covering all fundamental Python programming concepts, from basic syntax to object-oriented programming, with practical exercises and real-world projects.

## 📚 Overview

This repository contains a complete Python learning curriculum designed for beginners to master Python fundamentals. It includes:
- **15 Lessons** covering core Python concepts
- **Step-by-step learning materials** with code examples and explanations
- **Practical projects** ranging from mini-applications to full systems
- **Real-world applications** including calculators, games, and management systems

## 🎯 Learning Objectives

By completing this repository, you will understand:
-  Variables, data types, and how Python handles different types
-  User input/output and basic I/O operations
-  Operators and expression evaluation
-  Conditional statements and decision-making
-  Loop structures and iteration
-  Functions and code organization
-  String manipulation and text processing
-  Data structures: Lists, Tuples, Sets, and Dictionaries
-  File handling and persistence
-  Exception handling and error management
-  Modules and packages for code organization
-  Object-oriented programming (OOP) principles

## 🚀 Quick Start

### Prerequisites
- Python 3.7 or higher
- A text editor or IDE (VS Code, PyCharm, etc.)
- Basic terminal/command line knowledge

### Running the Lessons

1. **Navigate to a lesson directory:**
   ```bash
   cd 01_basics
   python lesson1.py
   ```

2. **View lesson descriptions:**
   Each lesson folder contains detailed explanations and examples in markdown files.

3. **Run projects:**
   ```bash
   cd 05_projects
   python calculator.py
   ```
